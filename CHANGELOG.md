# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-30

### Added
- Phase 1: Workspace Foundation with Monorepo structure, shared UI package, routing, and RBAC implementation.
- Phase 2: Support Hub backend capabilities (Tickets, Comments, Feature Flags).
- Phase 3: Shared Infrastructure (Organizations, Users, Cross-module sharing framework, Digests).
- Phase 4: Review Console backend APIs (Pull Requests, Merge validations, Approval flows).
- Phase 5: Production-ready frontends for `support-web` and `review-web` complete with full feature parity to the backend.
- Full Dockerization for deployment.
- comprehensive API documentation in `docs/`.
